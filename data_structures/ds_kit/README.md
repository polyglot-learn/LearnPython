# ds_kit

Six small data structures behind plain Python protocols (`len()`, iteration).

```bash
python3 -m data_structures.ds_kit     # six examples plus a self-check
```

| Class | Module | Highlights |
|---|---|---|
| `Stack`, `Queue`, `LinkedList` | `linear.py` | push/pop, deque-backed queue, in-place reverse |
| `MinHeap`, `Trie`, `LRUCache` | `indexed.py` | sift up/down, prefix completion, eviction order |

Standalone versions live next to this folder, e.g. `../min_heap.py`.
